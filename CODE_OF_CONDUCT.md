# Code of conduct

Be respectful, constructive, and welcoming. Critique ideas and code without personal attacks.
Harassment, threats, discriminatory abuse, and publishing another person's private information
are not acceptable in issues, pull requests, discussions, or other project spaces.

Report conduct concerns privately to the maintainer at me@nommyt.com. The maintainer may edit or
remove harmful content, close discussions, or restrict participation to protect the community.
The same expectations apply to maintainers and contributors.
